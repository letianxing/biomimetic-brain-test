小圆：六项验收与准确率计算
更新：2026-09-15

先读结论
这份说明按当前实际代码写，不把自动测试通过当成现场准确率。
页面上的0.78、0.94等是模型相似度/置信分数，不代表78%、94%的识别准确率。
日常交互已由统一策略控制：视觉关注、听觉关注、环境对话、对我说话、回话目标保持、事件定向。最终ASR从同一策略的历史证据判定，避免上游旧的放行状态直接触发TTS。
完整多说话人重叠转写、完整麦格克读唇/音素融合仍不具备，不能把这两项标为已通过。
系统目前关闭；按“Mac全系统启动与三项验收.txt”启动。注册只需说话，8092只用于观察和验收。

统一测试准备
准备A（主人）、B（熟人）、C（未注册者）。真实身份由你事先记录，不以机器人给出的标签当标准答案。
正常入口：A说“你好小圆，我叫小天，请记住我，我是你的主人。”B使用不同称呼并去掉主人声明。
先轮流说话，再增加距离、侧脸、逆光、背景声音，最后才测重叠。不同条件分别计分。
每种场景先重复10次用于发现问题，记录正确数/总数；0/10次错误不能证明错误率为零。不要用同一次视频里的数千个相邻帧充当数千次独立测试。
推荐逐试次记录：试次ID、场景、真实说话人、镜头人物、是否对机器人说、原话、声纹ID、人脸ID、最终Person ID、注意力目标/阶段、ASR、utterance_id、送入模型的记忆、回复、错误类型、延迟。
测试中的“未知”单独统计：它不是错认成另一个人，但属于未成功识别，不能从成功率分母里偷偷去掉。

一、声纹、人脸与融合注册
当前机制：
1. 声纹使用CampPlus模型。普通识别将本次声纹与本地已存模板做余弦匹配，当前阈值0.48。
2. 正式语音注册按具体utterance_id取样，至少两秒，分两段分别提取声纹，相似度至少0.60，再平均归一化为模板；回声、样本过期/变化、重叠等检查不通过会要求重试。
3. 没注册过的人，在干净、非回声、低重叠且至少1.5秒的有效发言中自动建立stranger_编号；再次匹配时复用编号。模型仍可能把一人拆成多ID或把两人误合并，必须实测。
4. 人脸使用YuNet检测、SFace提取模板。正式融合注册要求同一跟踪人脸至少5份连续特征、至少2帧有效唇动证据，样本对平均模板的相似度至少0.70；普通人脸识别阈值为0.38。
5. 融合注册不是把两个向量拼起来，而是把分别校验过的声纹和人脸绑定到同一个Person ID。两边先预检再保存；若写入期间另一边失败，会报告部分完成，不能算成功。
6. 已知人声再次注册会返回已认识。陌生编号升级正式身份会保留别名关联。稳定模板使用稳定事件标识去重，不按每句话重复创建Person。
7. 主识别路径使用本地模板：voice-detection/config/speaker_profiles.json、vision-detection/config/identities.local.json；HRI保存身份档案与对话记忆，身份库会话为identity-registry。

如何测试：
- 注册后，用未用于注册的新句子测试声纹，不只重复注册口令。每人单独在镜头外说话，测纯声纹。
- 人不说话，分别进入镜头、变化距离和轻微角度，测纯人脸。
- A、B分别同时出声和出镜，测正确组合；再让A出镜而B说话，检查不会把A的脸改成B。
- 重复注册、退出并重新启动，再说新句子，检查Person ID和档案是否保持稳定。
- C以不同句子多次讲话，检查同一陌生人是否复用ID；另一个陌生人不应被合并到C。

计算：
注册正确率 = 身份和两种模板都正确、且系统报告完成的尝试 / 预先定义的正常注册尝试。
错误绑定率 = 人脸属于A而声纹属于B的已完成注册 / 全部已完成注册。
声纹识别正确率、人脸识别正确率分别 = 正确ID次数 / 各自全部测试次数（包含未知）。
错认率 = 实际不是某已登记人的试次中，被认成该人的次数 / 此类试次。
拒认率 = 已登记本人试次中，被判未知的次数 / 本人试次。
同时报告错认成他人，不与未知混为一类。
重复建档率 = 同一真人被拆成多个未关联Person ID的人数 / 测试人数。别名已归一到同一正式ID的不算重复。
错误合并要单独记：两个真人共享了一个错误的Person ID。

二、聚焦时的身份准确性
不要只看“当前目标”或截图中的一行owner。
8092原始数据分别核对：
- vision.state.people[].person_id / role / identity_confidence / face_id：视觉身份。
- voice.last_transcript.speaker.speaker_id / speaker_role / similarity：这句话的声纹身份。不要拿另一句的last_speaker比较。
- utterances[].person_id：最终发言归属；用utterance_id与上述ASR对应。
- utterances[].visual_person_id / identity_conflict / identity_resolution：视听是否一致、冲突如何处理。
- utterances[].evidence.vision：当时的人脸ID、身份分数、注视、唇动；evidence.observed_at_ms和transcript_end_ms核对时差。
face_confidence是人脸检测分数，不是认出某个人的分数。

期望：两者正确且一致最好；冲突时以可靠声纹作为说话人，但不改写冲突人脸身份。只有一个人出镜也不能把旁人的声纹自动绑到他脸上。
计算：目标正确率 = 实际选对交互对象的试次 / 应选择目标的试次。
身份正确率 = 最终Person ID正确的发言 / 已聚焦期间全部发言。
双模态都正确率 = 声纹和人脸同时与真人一致的试次 / 需要双模态的试次。
冲突处理正确率 = 保留正确声纹归属且没有错绑人脸的冲突试次 / 全部冲突试次。
“声纹和人脸两个输出一样”不一定正确，两者可能一起认错。

三、聚焦后的回答与记忆
使用模型无法凭常识猜出的事实：
A：“这次计划代号是蓝纸鹤，周六下午三点在北门见。”
B：“我负责带柠檬水，不带咖啡。”
A转向机器人问：“小圆，我们几点在哪见？谁带什么？”
应包含：周六三点、北门、B带柠檬水，不混为A带咖啡。
再问：“是在东门吗？”应按记忆纠正。
再明确更新：“改成下午四点。”之后询问当前时间应答四点；询问最早约定可以说明原先三点。
问没说过的“几瓶柠檬水？”应说明不知道，不能编数字。
重启并更换会话后再问旧计划，检验同一用户空间、同一机器人范围内的跨会话召回。

逐层检查：
1. ASR和Person ID是否正确。
2. 历史ASR/记忆面板是否真的存到了这些事实。
3. Brain本次上下文中是否有这些事实：current_turn.memories和recent_conversation。
4. 最后才评判回复。历史记录正确但没有进入本次上下文，是召回问题；上下文正确但答错，是生成问题。
当前会把当前问题、说话人及其别名相关记忆、环境/机器人历史、最近两分钟最多8条对话和感知证据交给千问。总量有上限，不代表每次把全部记忆都塞给模型。

计算：
必要事实召回率 = 本次实际送入模型的必要事实数 / 正确回答所需事实数。
回答要点正确率 = 回复中正确回答的预定要点数 / 应回答要点数。
无依据陈述率 = 回复中没有记录/输入支持的事实陈述数 / 回复事实陈述总数。
端到端成功率 = 身份正确、问题回答正确且成功播放的轮数 / 应回复轮数；漏答也算失败。
另算“输入、身份和检索都正确时”的回答正确率，用于定位千问问题，不能拿这个条件指标代替总体成功率。
测句末到播放的延迟时记录中位数和较慢的P95；服务时间戳是播放确认，不等同于声卡首采样，必要时用现场录像复核。

四、不聚焦时的旁人记忆
A、B互相看着对方，轮流说上述计划；机器人不应接话，但两人的话必须能查到。
再由C加入，检查陌生编号稳定、没有混入A/B。让机器人自己说话后保持安静，检查自身回声不会变成用户记忆。
按heard_utterance计算用户发言记录；dialogue_turn是机器人回复，brain_trace是过程记录，不要把它们算成同一句用户话的重复副本。
每句核对：原话、ASR、Person ID、是否对机器人说、时间、同轮utterance_id，以及当时可见人物。
“未对机器人说”不等于系统已确定是对B说；当前很多记录只能标为非机器人/听话人未知，不能当成明确的人际对话对象。

计算：
记录覆盖率 = 被保存的真实发言数 / 实际发言数。
中文CER（字错误率） = (替换字数+漏字数+多字数) / 参考原话字数；统一忽略标点，不能只凭大意相似。
归属正确率 = Person ID正确的发言数 / 实际发言数。
联合正确率 = 文字关键内容、说话人、对话对象标记都正确的句数 / 实际发言数。
重复率 = 同一真实发言多存的副本数 / 实际发言数。
回声污染率 = 被误存为用户发言的机器人回声数 / 机器人播放轮数。
旁人误插话率 = 机器人对未被叫到的旁人对话开口次数 / 旁人对话试次。
先用Baseline测全部环境记录。SpeakerBeam目标提取是另一项测试，不能用“只保留目标声音”模式证明旁人的话也完整保存。
当前不能保证多人重叠时每个人都逐字正确；该场景单独列压力项，不把轮流说话的分数当重叠成绩。

五、注意力逐项测试
A. 静默注视：主人、熟人、陌生人分别持续看机器人。约800ms后应VISUAL_FOCUS；陌生人不应因此被叫主人或触发主人问候。
B. 看别处/短暂一瞥：不应立刻抢走目标；画面过期或人离开时要释放目标。
C. 被点名：镜头里无人，普通音量说“小圆”。应LISTENING/AUDIO_FOCUS并答“我在，你说”，不是惊跳；方向有效时显示对应声源方向，未知则保持未知。
D. 旁人提及名字：“昨天小圆回答过。”不应仅凭句中出现名字就回复。
E. 视听一致：一个人看机器人并说话，唇动、时间、方向匹配，进入LISTENING；最终句必须有同一套门控证据。
F. 多人竞争：A讲话期间B只看机器人，B不应抢断；B确实对机器人发言或叫名字后，允许切换并打断。
G. 方向冲突：改变阵列前后左右位置，比较实际方位和输出；原始通道缺失时direction_valid必须为false，不能把虚假60度当测量成功。
方向误差取圆周最小角差；只有有效真实方向样本才计算，并同时报告有效覆盖率。
H. 大声音：音量突变可短暂定向；持续背景噪声应降低优先级。只有符合惊跳门槛的事件才进入惊跳短叹。
I. 视觉惊跳：同类框显著快速增大，或已支持物体突然大面积出现并连续确认。普通入镜、框抖动不应反复惊跳；冷却8秒。
J. 鸡尾酒：先测目标选择和切换，再测重叠转写。两者分开计分。
K. 双闪：摄像头观察短亮度脉冲，配两次短窄带声音脉冲；查看crossmodal_events的observed_flash_count/observed_tone_count/double_flash_candidate。增大声光间隔后不应绑定。这里是实际事件时间绑定，不是宣称机器人产生人类错觉。
L. 麦格克：当前仅有双唇音与闭唇几何冲突检测；查看av_speech_consistency的valid/conflict。不能据此宣称完整ba+ga→da音素融合通过。普通多音节讲话没有完整读唇对照模型。
正常20fps视觉约50ms一帧，极短闪光可能漏采；这属于输入时间分辨率，需与融合逻辑错误分开。

注意力指标：
正确吸引率 = 应转移而成功转移次数 / 应转移试次。
误吸引率 = 不应转移却转移次数 / 不应转移试次。
切换延迟 = 明确触发时刻到目标稳定的时间；报告中位数和P95。
振荡次数 = 目标没有真实变化却在多个人之间来回切换次数。

六、主人接话、主动搭话与打断的冲突
1. 主人出现但未锁定：不问候。
2. 锁定主人后持续安静：从锁定时刻起等待5秒，再准备主动回复；实际出声还要加模型/TTS耗时。
3. 第4秒主人开口：等待被重置；若是对机器人问话则回答问题，不先问候。
4. 主人此前与B聊天，转向机器人说“你说是吧？”：以刚才讨论内容接话，回答赞同/不赞同/不确定；不能突然说“你回来啦”。
5. 问候还在生成时有人开始交谈：取消未播出的问候，记录为延后主动问候，不算播放被打断。
6. 普通回复正在播放，B只看一眼或对A聊天：继续播放，并记录B的发言，不打断。
7. 播放中用户直接叫名字，或目标人物明确对机器人说话：注意力确认后取消旧生成和待播分句，再回答新输入；旧回复不能后来又冒出来。
8. 确认惊跳与用户问题同时到达：惊跳优先；新问题保留等待，短叹完成后处理，不丢问题，不自动整段重播被取消的旧答复。
9. 主动生成期间失去主人锁定：取消；重新稳定锁定后重新等待。已经实际问候/交谈过，本次在场不再重复问候。
10. owner与熟人身份交替或置信度波动：不能重复问候，也不能因角色不确定叫错主人。

冲突指标：
正确打断率 = 应打断且实际停止旧播放的次数 / 应打断试次。
误打断率 = 不应打断但停止旧播放的次数 / 不应打断试次。
打断延迟 = 有效注意力触发到旧声音实际停止的时间，不是只看计数加1。
问候抢话率 = 用户正发问却先播放问候的次数 / 冲突试次。
重复问候率、旧回复复活次数、惊跳后待处理问题丢失次数分别记录。
主动问候等待时间从锁定后连续安静开始计算，不从主人进入画面或上次系统启动开始算。

观察位置
8092：实时身份/目标/阶段、VAD/ASR、TTS当前片段、主动等待倒计时、历史记录、实际送入模型的记忆、回溯时间线。
关键事件：attention_changed、gate_accepted、gate_rejected、playback_started、playback_stopped、interrupted、proactive_deferred、user_turn_deferred、echo_rejected。
只看到target_id不等于允许回复。最终句是否回复看该utterance_id对应的attention.listen/addressed_to_robot及历史证据；实时LISTENING表示当前正在听对它的发言，VISUAL_FOCUS/AUDIO_FOCUS是关注与等待。不要拿一句结束后的实时等待状态，代替那句话当时的门控结果。
先判定输入/身份，再判注意力，再判存储与召回，最后判回复和播放；每层同时保留总体成绩，不能把失败样本全部排除后报高分。

最新分级淡出、VAP、声学特征和目标保持参数以同目录“仿生打断与注意力保持更新.txt”为准；旧的立即释放/统一打断时间参数已被替换。
